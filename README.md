# CHECKMATE — Glass Orbit

An interactive chess-inspired visual experience built around particles, motion and glassmorphism.

Checkmate transforms chess pieces into dynamic particle formations, creating an immersive visual playground where movement and interaction shape the experience.

## Features

- **Interactive Chess Pieces:** Explore six chess pieces — King, Queen, Bishop, Knight, Rook and Pawn.
- **Particle Animations:** Watch particles form the outline of chess pieces and respond to movement.
- **Magnet Effect:** Attract particles towards your cursor.
- **Gravity Effect:** Experience the board and its elements falling and returning to their original positions.
- **Shatter Effect:** Move quickly across the board to scatter particles and break the glass-like board.
- **Procedural Sound:** Explore generated sound effects and musical tones.
- **Customisation:** Adjust particle density, outline elasticity and scatter intensity.
- **Dynamic Layouts:** Experiment with different particle arrangements and visual compositions.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
- SVG
- Web Audio API

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/abirami-cs26/Checkmate.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or installations are required.
